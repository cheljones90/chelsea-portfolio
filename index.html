How I Work

Design is a systems problem.

01

Research before rectangles

Every project starts with understanding the user's actual workflow. I conduct interviews, synthesize findings, and map the competitive landscape before a single screen is drawn.

02

Design to the system

Individual screens are decisions. Patterns are strategy. I design with the full ecosystem in mind — how components connect, how flows scale, how edge cases get handled.

03

Advocate relentlessly

Good design requires someone willing to push back. I fight for the right solution with evidence — user research, competitive data, and prototypes that make the argument visual.
